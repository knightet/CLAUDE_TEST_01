4. 효과 있었던 변경

  • 조건 판단·계산을 코드 엔진으로: 같은 설명서를 줘도 GPT 계산은 개발 42/100 (42%) / 홀드아웃 5/15 (33%), 엔진은 100/100 (100%) / 15/15 (100%)
  • 질문 해석도 코드 규칙으로: 같은 질문이 실행마다 다르게 해석되던 문제 차단 (예: "SKT 통신요금 5만원"을 실적 질문으로 읽음). AI는 코드가 못 찾은 가맹점 이름 후보만, 질문에 그대로 있을 때만 사용
  • 답변 문장도 코드: 계산에 없는 숫자·카드가 나갈 수 없음
  • 카드 데이터 표준 구조 + 사람 검수: 검수에서 노리 통신요금(5만원 미만 0원) 계산 오류 발견·수정
  • 공격 테스트·성질 검사: "gs 25 12000원"을 2,512,000원으로 읽던 오류 등 고정 문항으로는 못 찾던 오류를 찾음

5. 남은 한계

  • 홀드아웃이 작음: 15문항. 정답 계산도 AI가 작성(카드 데이터는 사람 검수). 처음 보는 표현 유형에서는 87%(26/30)였던 기록이 있어, 실제 사용자 표현에서 해석 오류가 날 수 있음
  • 안내 부족 사례 (측정 뒤 발견): 평일에 "이마트 5만원"을 물으면 숫자는 맞지만(LOCA 400원, 스카이패스 50마일) "주말이면 Mr.Life 5,000원" 안내가 없고, 3위에 0원 카드가 표시됨 — 동결 중이라 고치지 않음
  • 설명서: 헤이영(2022)·K-패스(2024)는 오래됨, Mr.Life는 공식 설명서가 아닌 홈페이지 자료
  • 측정 조건: gpt-4o-mini 한 모델, 한 번 실행. 비교 방식(빈손·고치기 전)은 실행마다 점수가 조금 달라짐 (예: 개발 문항 고치기 전 39/100 → 이번 42/100)
  • 실제 사용량: 이번 달 사용은 사용자가 "썼어요"로 기록한 것만 반영. 카드사 실제 집계와 다를 수 있음
