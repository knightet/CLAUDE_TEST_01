카드 혜택 챗봇 직접 테스트 질문 (2026-10-06)
기대 답은 설명서로 계산해 둔 정답(테스트 정답)에서 가져왔어요. 다르게 나오면 화면을 캡처해서 알려주세요.

[시작 전 설정] 이대로 맞춰야 기대 답과 같게 나와요
1. 왼쪽 '내 카드' → 한 번에 선택 → [모두 해제]  (아무것도 고르지 않으면 9장 전체로 계산)
2. [전월 실적 최고 구간으로 채우기] 한 번 누르기
3. Youth Club '선택형 서비스팩', 스카이패스 '마일리지 옵션'은 [선택 안 함]
4. 아래 '이번 달 결제 기록'이 있으면 모두 [되돌리기]
5. 입력창 왼쪽 '질문 연결'은 [자동]
6. 결과는 상위 3개만 나와요. 금액이 같은 카드끼리는 순서가 바뀌어도 정상이에요.

C. 조건·전월 실적
======================================================================
C1  전월 25만원 썼는데 노리 지하철 1500원
    → 노리 0원 (대중교통 할인은 전월 30만원 이상 필요)
C2  지난달 실적 20만원인데 노리로 지하철 1500원
    → 노리 0원
C3  전월 30만원 채웠어. 노리로 지하철 1500원
    → 노리 150원
C4  아파트관리비 실적에 들어가?
    → 카드마다 "포함 / 제외"와 설명서 파일·페이지가 나와야 함 ("가능성이 높다" 같은 애매한 말이 나오면 오류)
C5  오후 2시 스타벅스 카드 충전 5만원
    → 스타벅스 할인(NH 50%, 노리 20% 등)이 나오면 오류 (선불 충전은 제외)
C6  굿데이 플래티늄 연회비 얼마야?
    → 연회비 참고에 "플래티늄 10만원"이 나와야 함

F. 질문 연결 (입력창 왼쪽 자동 / 이어서 / 새 질문)
======================================================================
F1  [자동] 토요일 이마트 6만원 → 일요일이면?
    → "이전 질문에 이어서" + Mr.Life 5,000
F2  [자동] 오후 2시 스벅 15000원 → 노리는?
    → "이전 질문에 이어서" + 노리 3,000
F3  [자동] 토요일 이마트 6만원 → 롯데월드 놀러가려고 하는데 카드 추천
    → 이어받지 않음 (6만원·토요일이 붙으면 오류)
F4  [새 질문] 토요일 이마트 6만원 → 그럼 2만원이면?
    → "새 질문으로 계산" + 어디서 결제하는지 되물음
F5  [이어서] 토요일 이마트 6만원 → 롯데마트는?
    → "(이어서 선택)" + 롯데마트 60,000원, 토요일 → Mr.Life 5,000

G. 사용 기록 ("이 카드를 썼나요?")
======================================================================
G1  노리 카드 설정에서 전월 실적을 400,000원으로 바꾸기 (통합한도 월 2만원)
    "노리로 오후 2시 스벅 15000원" → 3,000원 → [썼어요]
    같은 질문 + [썼어요]를 반복하면: 1~6번째 3,000원, 7번째 2,000원, 8번째 0원
G2  (설정을 처음 상태로 되돌리고) "오후 2시 스벅 15000원" → NH 5,000에서 [썼어요]
    같은 질문 다시 → NH는 하루 1회라 빠지고 노리 3,000 / 굿데이 1,500 / 헤이영 1,000
G3  '이번 달 결제 기록'에서 [되돌리기]
    → 기록이 사라지고, 같은 질문을 다시 하면 처음 결과로 돌아감
