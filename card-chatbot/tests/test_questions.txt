카드 혜택 챗봇 수동 테스트 질문 모음 (카드 9장 버전, 2026-10-01)
=====================================================================

사용법
- 서버 실행 후 http://localhost:8000 에서 질문을 순서대로 입력합니다.
- [ ] 칸에 결과를 적습니다.  O = 기대대로, X = 틀림, △ = 애매함
- 틀린 답은 화면 캡처와 함께 알려 주면 원인을 고치고 자동 테스트에 추가합니다.
- 새로고침하면 대화가 초기화됩니다. 파트(또는 묶음)를 시작할 때마다 새로고침하세요.

기본 상태 (특별한 말이 없으면 이 상태에서 질문)
- 내 카드: [한 번에 선택] → "모두 해제" (= 9장 전체로 계산)
- 전월 실적: "전월 실적 최고 구간으로 채우기" 버튼을 한 번 누른 상태
    노리·헤이영·Mr.Life 1,000,000 / 굿데이 1,200,000 / K-패스·NH 300,000 / Youth Club 200,000
- 선택 옵션(서비스팩·마일리지 옵션), 프로모션 가입, 신규 특례, 이번 달 사용 입력: 모두 비워 둠
- 심야·주말 혜택이 있어서 시간·요일이 결과를 바꿀 수 있는 질문은 시간을 질문에 적어 두었습니다.

기대값 읽는 법
- "A / B / C" = 상위 3개 순서와 금액. 금액이 같은 카드는 순서가 바뀌어도 O.
- 마일리지 카드(삼성 스카이패스)는 원화 혜택 카드 뒤에 나옵니다.
